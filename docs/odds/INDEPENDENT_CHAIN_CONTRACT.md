# Gate A: independent upstream chain claims — research only

Two book logos or two aggregator rows are **not** independent original bookmaker sources. The new offline `inspect` contract requires exact selection identity, distinct bookmaker and upstream-chain IDs, separate original receipt IDs/hashes, provider-observed and local-captured UTC, and claimed external source attestation. It rejects stale/missing/post-decision records. It returns **PAPER/0u** only.

**Important limitation:** The `EXTERNAL_VERIFIED` value is a caller assertion, NOT cryptographic proof. This contract does not authenticate HTTP transport, provider permissions, bytes or bookmaker origin. Production Gate A requires an independently witnessed private receipt chain, original bytes held outside public GitHub, a trusted source registry and separate independent-book authentication. This module is not wired to any release/promotion path. All seven sports are accepted as identity labels; no market family is certified.

Synthetic tests cannot close Gate A. No odds, tokens, screenshots or restricted historical boards should be committed.
