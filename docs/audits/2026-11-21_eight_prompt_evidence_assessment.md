- The same workbook MODEL_OUTPUTS has no populated model probability in the sampled populated/formatted output grid, and its displayed placeholders are `GATED` / `0`, not projections. The archive's market statuses for MLB sometimes say historical OOS validated while `Live_Output_Ready=FALSE`; do not confuse those retrospective notes with current offered-market acceptance.
- The November 9 CBB Drive file contains **496 derived rows** expanded from **248 original board rows** (two opposing prices per board market). Its PROVENANCE tab explicitly says original engine picks.csv and original finals.json are missing, book-time authentication unverified, and it remains PAPER/0u. Do **not** score 496 independent selected wagers.
- On main, `quant_evidence._asof_check` requires model/data and market times before kickoff but has **no mandatory selected_utc or rules_effective_utc for qualified rows**. An originally pregame quote could be selected retrospectively without detection. PR #367 proposes to close this loophole but remains open and unmerged. Blocking original-source authentication is separately required.
- On main, `quant_evidence._summary` calculates model Brier on all decided records and market Brier on its subset with paired market prices; this can produce an **unmatched-population comparison**. PR #348 adds paired-on-identical-rows model-vs-market Brier but is currently unmerged.
- Main `quant_evidence._cluster_ci` resamples events rather than individual props, which is better for correlated bets, but is descriptive only and defaults to 400 repetitions; it provides no real edge proof without authenticated prospective denominators.
- The current historic release matrix (`asof_date_ct=2026-11-15`) identifies policy `SPORTSEDGE_RISK_2026_11_15_LOCK_V1`; current `RISK_POLICY.md` identifies `SPORTSEDGE_STRICT_V21_V22_20261115_R1`. This is **documented historical policy-version drift**, not license to rewrite a frozen matrix.
