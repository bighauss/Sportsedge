# RUN IT STANDARD — addendum: CFB + CBB (Isaac, Nov 15 2026)

Same pipeline as the main RUN IT STANDARD (50/50 model + season-stats matchup, injuries, travel, pace, weather, raw + 30/70 blended EV, projection-contradiction filter, Munich card format). Sport-specific scales:

## CFB
- Season-stats matchup: avg(team PPG, opp PA/G), opponent-adjusted when SP+/Sasser/Corbie available (cross-check, don't replace).
- Home field: +2.5 (neutral 0). Injuries: starting QB out -4 to -7; star skill -1.5; multiple DBs out opp +1.5; OL starter -0.75.
- Travel: 2+ time zones -0.5; short week -0.5.
- Pace: plays/game vs FBS avg, scale total.
- Weather (live only): wind 15+ -2 total; heavy rain/snow -2 to -3.
- Pricing SDs: margin 15.5, total 15, team total 11, 1H = 0.5 x total / SD 11.

## CBB
- Matchup: adjusted offense vs adjusted defense per 100 possessions x projected possessions (avg of both tempos).
- Home court +3.0 (neutral 0). Injuries: top-2 usage player out -2 to -4; rotation player -0.5 to -1.
- Travel: 2+ time zones or back-to-back road -0.75.
- Pace: tempo average sets possessions; total moves with it.
- Weather: none (indoor).
- Pricing SDs: margin 11, total 11, team total 8, 1H = 0.47 x total / SD 8.
- Props: same scaling method; elasticity points/rebounds/assists 0.6, 3PM 0.5.
