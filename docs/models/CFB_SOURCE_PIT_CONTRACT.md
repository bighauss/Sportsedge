# CFB original-source point-in-time preflight (research only)

This module does **not** use an unverified CFBD API, scrape a sportsbook, or generate/replace SportsEdge CFB projections. It validates five **operator-permitted original byte streams** and a separately retained source/capture manifest that can be collected prospectively. It does **not** authenticate publisher clocks or identities; original local file SHA-256 proves only that bytes haven't changed since a separately retained hash was calculated. No original CFB data or provider credentials were included in this PR.

Run synthetic checks:

```sh
python -m unittest models.cfb.test_cfb_source_pit_contract -v
```

Use `models.cfb.cfb_source_pit_contract.audit(original_bytes, manifest)` in a private operator session, passing **original** JSON byte strings under the exact keys `game`, `team_stats`, `qb`, `weather`, `injuries`. This is a strict normalized **contract**, not a promise that CFBD publishes these fields in this exact shape. A licensed adapter must map independently received originals while separately retaining those original responses and their permissions/lineage.

The manifest requires `schema="sportsedge-cfb-source-pit-v1"`, exact `event_id` and integer `season`, `frozen_utc`, `kickoff_utc`, a `source_clock_receipts` object with all five source keys, and a `market_family_census` array. Each source receipt declares a nonempty upstream `provider`, SHA-256 lowercase 64-hex, and `published_utc`, `observed_utc`, `captured_utc` in strict non-future order. The entire source chain must precede the declared pregame freeze. The game source must agree exactly with event, season, kickoff, and distinct home/away team IDs; `team_stats` and `qb` must contain those two teams only. The starter QB ID must be stable, and `starter_status` CONFIRMED or else explicitly held. The weather must be marked a **forecast**, not a retrospective actual, and match the exact event. Injuries must be an explicit list (possibly empty, but **not proof there were no injuries**), with exact team and player IDs and a status. Unresolved participation remains visible as a blocker.

All nine market *families* need a row: `ML`, `SPREAD`, `TOTAL`, `TEAM_TOTAL`, `PLAYER_PROP`, `PERIOD`, `SPECIAL`, `ALTERNATE`, `SGP`. Each row is one of `CAPTURED_UNVERIFIED` (a caller-claimed receipt hash required), `NOT_CAPTURED`, or `BLOCKED` (reason required). A bare `NOT_OFFERED` is **refused** absent an authenticated original whole-market provider catalog. The family-level list is **not** a complete offered outcome/alternate ladder inventory. Provider-native individual lines, period, player IDs, spread and team-total sides require their own quote census in Gate A. A locally complete nine-family list never certifies an offered slate.

For synthetic test input the output can show `PAPER_0U_LOCAL_CFB_SOURCE_CLAIMS_ONLY`. For any uncertain QB, old weather actual, unresolved injury or missing family quote, it returns `BLOCK` with reasons. Every path returns `source_externally_authenticated=false`, `market_inventory_authenticated=false`, `model_projections_generated=false`, `gate_a_closed=false`, `gate_b_closed=false`, `official_counted=0`, and `approved_stake_u=0`. Duplicate raw JSON keys, NaN/Infinity/exponent overflow, wrong season, cross-game weather, borrowed QB/team identifiers, incomplete sources, late publishes, late capture, bad sample numbers and repeated injuries refuse the entire audit.

**Remaining CFB #191 work:** connect an authorized exact-event original CFBD/team/starter/weather pipeline to the generic prospective seven-sport private freeze ledger, separately preserve a true provider-native book offer inventory (not an invented Odds API/DK endpoint), freeze original outputs from a tested model version before kickoff, and grade chronologically on previously untouched games with all exclusions and 0u retained. Until genuine independent A–E receipts and signed owner promotion exist, CFB sides, props and specialty markets remain PAPER/0u. Historical season-wide CFBD files downloaded after games are not valid pregame point-in-time evidence.
