# Forward holdout contract (research only)
`research.edge.forward_holdout_contract.evaluate(freeze, rows)` evaluates a preregistered binary, nonpush settled sample without cherry-picking settled winners. Preserves original denominator and unsettled count; rejects duplicate exact selection IDs, changed model hash, future features, post-event freeze, NaN, boolean outcomes/probabilities. Computes model and book Brier/log loss on the same settled subset. No retrospective filter, no implied certification. Does not independently authenticate original provider odds, fitted model, registration time or settlement receipts. Binary outcomes only: pushes/voids/dead heats and multi-outcome markets require separate explicit graders; do not convert them silently to binary. Book baseline must be prepared externally from a same-selection independently sourced original quote. No market is promoted and all stakes remain PAPER/0u. Gate A/B/C/D/E still open.
